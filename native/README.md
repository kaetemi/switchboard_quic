# The native QUIC shim (`native/sbq`)

`sbq` is a small Rust crate over [quinn](https://github.com/quinn-rs/quinn) 0.11 (quinn-proto, rustls with ring, tokio) that exposes a flat `extern "C"` ABI. The native stream provider of `switchboard_quic` (`lib/src/native/`) calls it through `dart:ffi`. The crate builds a `cdylib` (what Dart loads) and a `staticlib` (for embedders that link it).

| Path | What |
| --- | --- |
| `sbq/src/lib.rs` | The ABI: constants, `SbqEvent`, `SbqStats` and every `sbq_*` function, with their contracts in doc comments. |
| `sbq/src/ctx.rs` | The runtime, contexts and their event queues, the notifier thread, the handle tables. |
| `sbq/src/config.rs` | TLS (rustls, TLS 1.3 only) and transport configuration, certificate verification, self-signed certificates. |
| `sbq/src/conn.rs`, `sbq/src/stream.rs` | Listeners, connections, streams. |
| `sbq/src/tests.rs` | A self test of the ABI through the exported functions (`cargo test`). |
| `sbq/include/sbq.h` | The C header, generated by cbindgen and checked in. |
| `sbq/prebuilt/<os>_<arch>/` | Where prebuilt libraries go (never committed, see below; `sbq/.gitignore` keeps them and `target/` out of git). |

Pinned by `Cargo.lock`: quinn 0.11.12, quinn-proto 0.11.19, quinn-udp 0.5.16, rustls 0.23.45, ring 0.17.14, tokio 1.53.2, rcgen 0.14.10, rustls-platform-verifier 0.7.1.

## How Dart gets the library

`hook/build.dart` (a Dart build hook, `package:hooks` and `package:code_assets`) provides the library as the code asset `package:switchboard_quic/sbq`, which the `@Native` bindings resolve. `dart run`, `dart test` and `dart build cli` run the hook; it

1. uses `sbq/prebuilt/<os>_<arch>/<file>` when that file exists (`linux_x64/libsbq.so`, `linux_arm64/libsbq.so`, `macos_arm64/libsbq.dylib`, `windows_x64/sbq.dll`, ...: the `OS` and `Architecture` names of `package:code_assets`);
2. otherwise, when the target is the host and `cargo` is on `PATH` (or in `~/.cargo/bin`), runs `cargo build --release` on `sbq/Cargo.toml` with the target directory `sbq/target/` and uses `sbq/target/release/<file>`; the first build takes about a minute (LTO), later ones only rebuild what changed;
3. otherwise fails, naming the prebuilt path it looked for and pointing at <https://rustup.rs>.

It prints which of the two it used (`switchboard_quic: native library from ...`, in `.dart_tool/hooks_runner/switchboard_quic/*/stdout.txt`) and writes the same line to `sbq_source.txt` in its output directory. The hook's result is cached: a prebuilt library placed after a cargo build is picked up once the cache is cleared (`rm -rf .dart_tool/hooks_runner`) or a source of the crate changes.

AOT: `dart build cli` compiles ahead of time and bundles the library (`bundle/bin/<program>`, `bundle/lib/libsbq.so`); ship the bundle directory as a whole. `dart compile exe` runs no build hooks (and refuses entry points under `bin/` of a package with a hook); a program compiled that way loads the library itself, into the process's global namespace, from `$SBQ_LIBRARY`, else from the executable's directory, else from `../lib` next to it. `tool/aot_smoke.sh` checks both.

## Building by hand

```sh
cd native/sbq
cargo build --release            # target/release/libsbq.so (+ libsbq.a)
cargo test                       # ABI self test
cargo clippy --all-targets       # kept warning-free
```

A prebuilt library for a release is the `cargo build --release` output for that target, copied to `sbq/prebuilt/<os>_<arch>/`. Cross builds go through `--target` with the matching linker, for example `x86_64-pc-windows-gnu` with MinGW (`CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER=x86_64-w64-mingw32-gcc`), or `aarch64-unknown-linux-gnu`. ring needs a C compiler for the target; nothing else is native. The release profile uses LTO, one codegen unit, `panic = "abort"` and strips symbols: the Linux x86-64 library is about 2.4 MB.

After changing the ABI, regenerate the header and the Dart bindings and commit both:

```sh
cd native/sbq && cbindgen --config cbindgen.toml --crate sbq --output include/sbq.h
cd ../.. && dart run ffigen --config ffigen.yaml     # lib/src/native/sbq_bindings.g.dart
```

`ffigen` needs libclang (found under `/usr/lib/llvm-*` on Debian and Ubuntu; set `llvm-path` in `ffigen.yaml` otherwise). Bump `SBQ_ABI_VERSION` when the ABI changes incompatibly; the Dart layer refuses a library with another version. Version 3 added the handshake deadline (`handshake_ms`, the last parameter of `sbq_client_config` and `sbq_server_config`); version 2, `sbq_stream_poll_reset`.

## The ABI in brief

* **Calls are synchronous and never wait on the network.** Something that cannot complete now returns `SBQ_WOULD_BLOCK` (0), and an event follows once it may succeed: `READABLE` after a read, `WRITABLE` after a write, `OPENED` after an open without stream credit. Every wait lives in Rust (quinn's wakers, tasks on a tokio runtime that owns the UDP sockets, with quinn-udp's GSO/GRO); the caller polls again once per event. Events can be spurious.
* **Events** go to a context (`sbq_init` makes one; the Dart layer makes one per isolate). A context's queue rings its doorbell callback, from one notifier thread, when it goes from empty to non-empty; the embedder then calls `sbq_poll` until it returns fewer events than asked. No thread calls the doorbell while it holds a quinn lock: quinn wakes its wakers with its connection lock held, and calling into Dart there deadlocked against a Dart thread waiting for that lock inside a leaf call. `sbq_shutdown` closes the context's connections and listeners and returns once no doorbell call is in progress (so it must not be a leaf call).
* **Handles** are 64-bit table ids, never pointers, never 0, unique in the process. A connection lives until `sbq_conn_release`, a stream until `sbq_stream_release`; `CLOSED` is reported once per connection.
* **Buffers** passed in are copied before the call returns (writes copy out of the caller's buffer); reads copy into the caller's buffer, and data not read stays in quinn, holding back the peer's flow control credit.
* **Results**: counts and handles are non-negative; `SBQ_FIN` (-1) and `SBQ_ERR_*` (-2 to -9) are negative; a result at or below `-SBQ_CODE_BASE` (-16) carries an application error code (`code = -result - 16`), the peer's reset code from a read and the peer's `STOP_SENDING` code from a write or finish. `sbq_last_error` describes the last failure on the calling thread.
* **Resets while nobody reads**: `sbq_stream_poll_reset` tells whether the peer reset the receive direction without reading from it (quinn discards a reset direction's unread data anyway), and otherwise arms the read waker, so that a READABLE follows the next change of the direction (data, FIN or the reset). The Dart layer calls it whenever no read is pending, so that `QuicStream.resetReceived` completes for a reader the layer above has paused.
* **Streams**: release a stream after both directions ended (FIN read, reset received or `sbq_stream_stop`; finish acknowledged, `STOP_SENDING` received, or reset), since a release behaves like quinn's drop (an open send direction is finished, an unread receive direction stopped with 0). The shim answers a peer's `STOP_SENDING` with a reset carrying the same code (RFC 9000 section 3.5), which quinn leaves to the application, also on a finished direction whose data is not acknowledged yet. `sbq_stream_set_priority` takes quinn's own levels (strict between levels, round robin within one); the Dart layer maps the provider contract's priority classes onto them (classes 1 and 0 share level 0, class 2 is level 1).
* **TLS**: TLS 1.3 only; ALPN lists in wire form; 0-RTT never (`max_early_data_size` 0 on servers, early data off on clients); no client certificates. A client verifies the server by the platform's trust store (rustls-platform-verifier), by pinned SHA-256 hashes of the certificate DER (compared in constant time), or not at all; the handshake signature is checked in every case. `CLOSED` with `SBQ_CLOSE_CERT_REJECTED` tells a rejected certificate from other handshake failures.
* **Transport**: bidirectional streams only (`initial_max_streams_uni` 0, no datagram parameter, so a peer cannot open a unidirectional stream without a transport error, and the provider's `incomingUnidirectionalStreams` never delivers one; raw QUIC has no draining signal either, so `draining` never completes); per-stream and connection receive windows, idle timeout and keep-alive as configured; the stream limit can be changed at runtime (`sbq_conn_set_max_bidi`). Outgoing connections share one UDP socket per address family, opened on first use and kept for the life of the process (by every context); a listener's socket stays open until it is closed and the connections it accepted have ended.
* **Handshake deadline**: quinn bounds a handshake only by the idle timeout, so without one a connect to a black hole would wait forever, and a listener would keep a half-open handshake forever. A configuration's `handshake_ms` bounds it in the shim (0: the idle timeout alone). A connect whose attempt (one per address tried; a dual-stack name ends within about the deadline plus 250 ms) does not complete in time ends with CLOSED `SBQ_CLOSE_TIMED_OUT`, as one the idle timeout ended; a listener abandons an incoming handshake not complete in time without announcing it. quinn closes an abandoned attempt and forgets it once the close has drained.

## Platforms

Built and tested here on Linux x86-64. quinn, rustls and ring support macOS, Windows, iOS and Android as targets; on Android, rustls-platform-verifier needs its JNI initialisation before platform verification works (pinned and unverified modes do not use it). Those targets are unbuilt so far.
